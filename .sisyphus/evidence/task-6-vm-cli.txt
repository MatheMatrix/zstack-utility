Custom options:
  --ssh-host=SSH_HOST   SSH host connection info. Format:
                        user:password@host[:port] or user@host[:port] (for SSH
                        key auth).
  --ssh-password=SSH_PASSWORD
                        SSH password override (used when --ssh-host omits
                        password).
  --ssh-key=SSH_KEY     SSH private key path for key-based authentication.
  --vm-deploy           Enable VM deployment runner for system tests.
  --target=TARGET       Target VM address in IP[:port] format (used with --vm-
                        deploy).
